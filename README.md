# InfluencerHub - Лендинг маркетплейса для инфлюенсеров и брендов

Современный и адаптивный лендинг для маркетплейса, который объединяет блогеров и инфлюенсеров с бизнесами.

## 🚀 Особенности

- **Современный дизайн** - Использует актуальные UI/UX тренды
- **Полностью адаптивный** - Отлично работает на всех устройствах
- **Интерактивность** - Анимации, модальные окна, плавная прокрутка
- **Высокая производительность** - Оптимизированный код и ленивая загрузка
- **Доступность** - Поддержка клавиатурной навигации и screen readers
- **SEO-оптимизация** - Правильная структура и мета-теги

## 📁 Структура проекта

```
/
├── index.html      # Основная HTML страница
├── styles.css      # CSS стили и адаптивный дизайн
├── script.js       # JavaScript для интерактивности
└── README.md       # Документация проекта
```

## 🎨 Дизайн и функциональность

### Секции лендинга:

1. **Header** - Навигация с логотипом и кнопками входа/регистрации
2. **Hero Section** - Главный экран с призывом к действию и статистикой
3. **Features** - Преимущества для инфлюенсеров и брендов
4. **How It Works** - Пошаговое описание процесса сотрудничества
5. **Testimonials** - Отзывы пользователей
6. **CTA Section** - Финальный призыв к действию
7. **Footer** - Контактная информация и ссылки

### Интерактивные элементы:

- **Мобильное меню** - Адаптивная навигация для мобильных устройств
- **Модальные окна** - Формы регистрации и входа
- **Анимации при скролле** - Плавное появление элементов
- **Счетчики** - Анимированная статистика в hero секции
- **Плавающие карточки** - Интерактивные элементы социальных сетей
- **Уведомления** - Система показа сообщений пользователю

## 🚀 Запуск проекта

### Локальный запуск:

1. Склонируйте или скачайте проект
2. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен http-server)
npx http-server

# PHP
php -S localhost:8000
```

3. Откройте браузер и перейдите по адресу `http://localhost:8000`

### Развертывание:

Проект готов к развертыванию на любом веб-сервере. Просто загрузите все файлы в корневую директорию сайта.

## 🔧 Кастомизация

### Цвета:
Основные цвета определены в CSS переменных в `:root`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #f59e0b;
    --accent-color: #06b6d4;
    /* ... другие переменные */
}
```

### Контент:
Весь текстовый контент можно легко изменить в файле `index.html`.

### Функциональность:
JavaScript код модульный и легко расширяется новыми функциями.
